┌──────────────────────────────────────────────────────────────────────────┐
│  🚀 HOW TO USE                                                           │
└──────────────────────────────────────────────────────────────────────────┘

STEP 1: Get Your Bardi Session Cookies
  1. Open browser → https://ipc.bardi.co.id/
  2. Login to your Bardi account
  3. Press F12 (DevTools) → Application → Cookies
  4. Copy these values:
     • s-sid
     • s-sid.sig
     • uid
     • clientId
     • deviceId

STEP 2: Update session.json
  Open:  backend/session.json
  Paste: Your cookie values into the file

STEP 3: Start Backend Server
  $ cd backend
  $ npm start
  
  You should see: 🚀 Server running on http://0.0.0.0:5000

STEP 4: Test the Service
  
  Option A - Node.js Test Script:
    $ cd backend
    $ npm run test:bardi
    
  Option B - Web Interface:
    1. Open: backend/test-bardi-web.html
    2. Click "Login" (admin/awak1234)
    3. Click "Test Session"
    4. Try other tests!
    
  Option C - cURL:
    $ curl http://localhost:5000/api/bardi/test-session

┌──────────────────────────────────────────────────────────────────────────┐
│  💡 USAGE EXAMPLE                                                        │
└──────────────────────────────────────────────────────────────────────────┘

JavaScript/Node.js:
```javascript
const axios = require('axios');

// 1. Login to your system
const { data } = await axios.post('http://localhost:5000/api/auth/login', {
  username: 'admin',
  password: 'awak1234'
});
const token = data.token;

// 2. Test Bardi session
const sessionTest = await axios.get(
  'http://localhost:5000/api/bardi/test-session'
);
console.log('Session valid:', sessionTest.data.success);

// 3. Get Bardi devices
const devices = await axios.get(
  'http://localhost:5000/api/bardi/devices',
  { headers: { Authorization: `Bearer ${token}` } }
);
console.log('Devices:', devices.data);
```

cURL:
```bash
# Login
TOKEN=$(curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"awak1234"}' \
  | jq -r '.token')

# Test session
curl http://localhost:5000/api/bardi/test-session

# Get devices
curl http://localhost:5000/api/bardi/devices \
  -H "Authorization: Bearer $TOKEN"
```

│  🐛 TROUBLESHOOTING                                                      │
└──────────────────────────────────────────────────────────────────────────┘

❌ "Session test failed" or 401 Error
   → Get fresh cookies from browser
   → Make sure you're still logged in to ipc.bardi.co.id
   → Verify all cookie values are copied correctly

❌ "Authentication required"
   → Login first: POST /api/auth/login
   → Include token in Authorization header

❌ "Cannot find session.json"
   → Copy session.json.template to session.json
   → Update with your actual cookie values

❌ "CORS error" in browser
   → Server has CORS enabled
   → Make sure backend is running on port 5000
   → Check API_BASE in test-bardi-web.html
